# KINAT 귀화용 종합평가 대비 웹앱

베트남인 배우자를 위한 **귀화용 종합평가(KINAT)** 시험 대비 PWA.
문제는 한국어, **해설은 전부 베트남어**. 매일 출석·정답 시 경험치가 쌓입니다.

> Ứng dụng ôn thi 귀화용 종합평가 (KINAT) — Bài đánh giá tổng hợp để nhập tịch Hàn Quốc.
> Câu hỏi bằng tiếng Hàn, **giải thích toàn bộ bằng tiếng Việt**.

## 시험 정보 (2025 사회통합프로그램 운영지침 기준)

**귀화용 종합평가 (KINAT — Korea Immigration and Naturalization Aptitude Test)**

| 구분 | 문항수 | 시간 | 배점 |
|---|---|---|---|
| 필기 · 객관식 | 36문항 | 50분 | 65점 (7문×1점 + 29문×2점) |
| 필기 · 작문형 | 4문항 → 1문제 통합 | 10분 | 10점 (4문×2.5점) |
| 구술 | 5문항 | 10분 | 25점 (5문×5점) |
| **합계** | **45문항** | **70분** | **100점** |

- **합격: 60점 이상** (소수점 절사)
- 작문형: 200자 원고지 1장. **답안지에 제목 쓰지 않음**
- 구술: 구술시험관 2명이 응시자 2명을 약 10분간 동시평가(2:2). 응시자에게는 **지문만** 제공
- 출제 범위: 한국어와 한국문화(1~4단계) + 한국사회이해 **기본과정 + 심화과정**
- 응시 수수료 38,000원 · 신청/결과: [kiiptest.org](https://www.kiiptest.org) · 합격증: [socinet.go.kr](https://www.socinet.go.kr)

**귀화면접심사 면제 조건**: 5단계 전체과정(기본+심화) 정규 이수완료 + 귀화용 종합평가 60점 이상 합격

## 기능

- **영역별 학습** — 한국어(어휘·문법·읽기), 사회, 교육, 문화, 정치, 경제, 법, 역사, 지리, 심화 5영역
- **실전 모의고사** — 36문항 / 50분 타이머 / 실제 배점(7×1점 + 29×2점) 반영 → 100점 환산 후 합격 판정
- **작문 연습** — 실제 형식대로 주제 + 하위질문 4개, 글자수 카운터(공백 제외), 모범답안·채점 포인트·유용한 표현
- **구술 연습** — 지문 + 질문 5개(지문관련 3 + 개별 2), 구어체 모범답안과 베트남어 힌트
- **오답노트** — 틀린 문제 자동 수집, **3회 연속 정답 시 졸업**
- **진짜 한국인 테스트** — 쉬어가는 K-상식 퀴즈. 맞히면 칭찬, 틀리면 베트남 남부 사투리로 놀림
- **경험치 / 레벨 / 연속출석** — 출석 +20~70XP, 정답 +6~10XP, 오답도 +2XP, 모의고사 합격 +150XP
- **통계** — 영역별 정답률, 약점 영역 자동 추천
- **PWA** — 아이폰/아이패드 홈 화면 추가, 오프라인 사용 가능

## 아이폰 / 아이패드에 앱처럼 설치하기

1. **Safari**로 배포 주소 열기 (Chrome 아님 — Safari여야 함)
2. 아래 **공유 버튼** `⬆️` 탭
3. **"홈 화면에 추가"** 선택
4. 홈 화면에 태극 아이콘 생성 → 앱처럼 전체화면 실행

## 수정 후 배포할 때 ⚠️

내용을 바꾸면 **`sw.js`의 `VERSION` 값을 반드시 올려야** 합니다.
그러지 않으면 아이폰에 옛날 캐시가 남아 변경사항이 안 보입니다.

```js
const VERSION = 'kinat-v1';   // → 'kinat-v2' 로 변경
```

그 다음:
```bash
git add -A && git commit -m "update" && git push
```

## 문항 추가 방법

`data/*.json` 에 아래 형식으로 추가하면 앱이 자동 인식합니다.
스키마 상세는 `data/_SPEC.md` 참조.

```json
{
  "id": "law-056",
  "domain": "law",
  "level": "basic",
  "topic": "경범죄",
  "points": 2,
  "passage": null,
  "q": "발문",
  "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
  "answer": 0,
  "explain_vi": "Đáp án ①. 베트남어 해설 (정답 근거 + 오답 이유)",
  "explain_ko": "한국어 요약",
  "keywords": ["핵심어"]
}
```

- `answer`는 **0부터** 시작 (①=0, ②=1, ③=2, ④=3)
- `choices`에 ①②③④를 직접 쓰지 말 것 — 앱이 자동으로 붙임
- 새 파일을 추가했다면 `js/data.js`의 `FILES` 배열과 `sw.js`의 `ASSETS`에도 추가
